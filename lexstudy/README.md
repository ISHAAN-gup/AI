# LexStudy — Law Student Companion

## Run locally
1. Open `lexstudy/index.html` in any modern browser.
2. Sign up and log in.
3. Use sidebar modules (Dashboard, Subjects, Notes, Cases, Quiz, Planner, Bare Act).

## Keyboard shortcuts
- `Alt + 1`: Dashboard
- `Alt + 2`: Notes
- `Alt + 3`: Quiz

## Data
All data is saved in browser LocalStorage under key `lexstudy_db`.
