# CLAT 2027 Prep Hub

A lightweight browser-based study app for CLAT 2027 aspirants.

## Run locally
1. Open `lexstudy/index.html` in any modern browser.
2. Sign up and log in.
3. Use the sidebar modules: Overview, Syllabus Tracker, Revision Notes, Passage Bank, Sectional Quiz, Study Planner, and Quick Capsules.

## Keyboard shortcuts
- `Alt + 1`: Overview
- `Alt + 2`: Revision Notes
- `Alt + 3`: Sectional Quiz

## Data
All data is saved in browser LocalStorage under key `lexstudy_db`.
